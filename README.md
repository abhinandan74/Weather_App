# 🌦 Weather App

A modern and responsive **Weather Application** that allows users to check real-time weather information for any city around the world.
The app fetches live weather data using a weather API and displays details like temperature, humidity, wind speed, and weather conditions in a clean and simple interface.

---

## 🚀 Features

* 🔍 Search weather by **city name**
* 🌡 Displays **current temperature**
* 💧 Shows **humidity level**
* 🌬 Shows **wind speed**
* ☁ Displays **weather condition with icons**
* 📱 **Responsive design** for mobile and desktop 

---

## 🛠 Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and responsive design
* **JavaScript** – Fetching and displaying API data
* **OpenWeather API** – Providing real-time weather data

## ⚙ Installation & Setup

1. **Clone the repository**

```bash
git clone https://github.com/your-username/weather-app.git
```

2. **Open the project folder**

```bash
cd weather-app
```

3. **Run the project**

Open `index.html` in your browser.

---

## 🔑 API Configuration

1. Create a free account on the OpenWeather website
2. Generate your **API key**
3. Replace the API key inside the JavaScript file

Example:

```javascript
const apiKey = "YOUR_API_KEY";
```
